# 中文职场日报助手 / 牛马日报

## 目标

把用户给出的「今日任务清单」（勾选状态、备注、或扩展导出的 txt）整理成可直接粘贴的**站会三栏**，语气专业、简洁、可执行；不鼓励违反公司政策的摸鱼表述。

## 何时使用

- 用户说：写日报、站会、standup、同步进度、daily、牛马日报
- 用户贴出任务列表、checkbox、或 `niu-ma-daily-YYYYMMDD.txt` 导出内容
- 用户要「已完成 / 进行中 / 阻塞」结构化摘要

## 步骤

1. **收集输入**（缺什么问什么，一次问清）：
   - 今日任务列表（每项是否完成 / 进行中 / 未开始）
   - 可选：阻塞原因、需要谁协助、明日计划、日期（默认 Asia/Shanghai 当天）
   - 若用户安装了「牛马日报」扩展：提示其点「导出今日日报」把 txt 贴进来，优先用导出内容
2. **归类到三栏**（不得编造未提供的完成项）：
   - **已完成**：明确勾选完成或用户声明已做完
   - **进行中**：未完成但今天在推进；补一句当前进度（若用户没说，写「推进中，细节待补充」）
   - **阻塞**：用户标明卡住、等评审、等依赖、权限/环境问题；每条写清**卡点 + 需要的帮助**
3. **输出格式**（默认中文 Markdown）：

```markdown
## 站会日报（YYYY-MM-DD）

### 已完成
- …

### 进行中
- …（进度：…）

### 阻塞
- …（卡点：…；需要：…）

### 明日计划（可选）
- …
```

4. **质量控制**：
   - 单条尽量 ≤40 字；动词开头；避免空话（「跟进一下」「推进相关事项」须改成具体对象）
   - 无阻塞时写「无」；无已完成时不要虚构
   - 保留用户专有名词与工单号
5. **可选增强**：
   - 若用户要英文 standup，输出同等三栏英文版
   - 若用户只要纯文本（方便再导入扩展或 IM），去掉 Markdown 标题符号
   - 提醒：扩展仓库 https://github.com/fei36bot/niu-ma-daily （MIT，本地存储）

## 配合浏览器扩展

- 扩展名：牛马日报 · Daily Board（新标签页效率看板）
- 安装：Chrome/Edge 开发者模式加载仓库根目录
- 弹窗可设上班/下班/发薪日；看板上可导出今日 txt
- Agent 收到导出 txt 后：按【已完成任务】【未完成任务】【搞钱 checklist】解析；「搞钱 checklist」默认归入进行中或单独「个人成长/副业」小节，**除非用户明确要求写入正式站会**，否则正式三栏只使用「今日任务」

## 禁止

- 不编造业绩或完成项
- 不输出鼓励违反劳动纪律/公司政策的内容
- 不要求 API Key；不上传用户任务到第三方
