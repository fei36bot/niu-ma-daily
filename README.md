# 牛马日报 · Daily Board

Chrome / Edge **新标签页**扩展：下班 / 周末 / 发薪倒计时 + 每日任务打卡 + 搞钱 checklist。  
数据只存本地（`chrome.storage.local`），**零上传**。

## 功能

- ⏱ 下班、周末、发薪倒计时（可改发薪日逻辑后续版本）
- ✅ 今日任务（本地持久化）
- 💰 搞钱 checklist 预设（空投 / X 日更等，可改）
- 🎨 深色「牛马」风 UI

## 安装（开发者模式）

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库根目录
4. 打开新标签页即可

## 灵感与合规

致敬「打工人 / 牛马」新标签页体验。**源码原创**，未使用闭源「牛马工具」任何代码。  
商店文案请避免鼓励违反公司政策的表述；本扩展定位为「效率看板 + 倒计时」。
