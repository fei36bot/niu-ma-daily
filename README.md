# 牛马日报 · Daily Board

Chrome / Edge **新标签页效率看板**：上班 / 下班 / 周末 / 发薪倒计时、每日任务打卡、搞钱 checklist，一键导出今日日报 txt。  
数据只存本地（`chrome.storage.local`），**零上传、零成本、MIT**。

> 源码原创，未使用任何闭源「牛马工具」代码。定位是效率看板，不是摸鱼教唆。

## 功能（v0.1.1）

- ⏱ 自定义**上班 / 下班 / 发薪日**（扩展弹窗设置，写入 `chrome.storage`）
- ✅ 今日任务本地持久化
- 💰 搞钱 checklist 预设（可勾选、可改文案）
- 📤 **导出今日日报**：生成含已完成 / 未完成任务、搞钱 checklist、时间戳的 `.txt` 并下载
- 📅 周末倒计时：工作日倒计到下周六 0 点；周末直接提示
- 🧩 配套 Cursor Skill：按任务清单生成站会三栏（见 `skill/`）

## 安装（开发者模式）

1. 打开 `chrome://extensions`（Edge：`edge://extensions`）
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本仓库根目录
4. 打开新标签页即可；点扩展图标可改作息与发薪日

## 导出示例字段

```
牛马日报 · 今日导出
时间：…（Asia/Shanghai）
作息：09:00 – 18:00 · 发薪日每月 10 日

【已完成任务】
【未完成任务】
【搞钱 checklist】
```
